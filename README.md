# 💳 SecurePay - Premium Checkout Experience

**SecurePay** es una interfaz de pago de alto nivel diseñada con una estética **Glassmorphism** y una experiencia de usuario (UX) interactiva. El proyecto destaca por su tarjeta de crédito dinámica con efectos 3D y un diseño totalmente responsivo que se adapta a cualquier dispositivo móvil.

## ✨ Características Principales

* **Glassmorphism UI:** Interfaz moderna basada en paneles traslúcidos y desenfoque de fondo.
* **Tarjeta Interactiva 3D:** La tarjeta se voltea automáticamente y actualiza los datos en tiempo real (Número, Nombre, Expiración y CVV).
* **Seguridad Visual:** Control de visibilidad para el campo CVV mediante un icono de "ojo" dinámico.
* **Navbar E-commerce:** Menú profesional y estilizado con acceso a catálogo, ofertas y carrito de compras.
* **Totalmente Responsivo:** Diseño optimizado para móviles mediante Media Queries y escalado dinámico.
* **Footer Profesional:** Sección minimalista con créditos del desarrollador y enlaces a redes sociales.

## 🚀 Tecnologías Utilizadas

* **HTML5 & CSS3:** Estructura y estilos avanzados (Animaciones, Flexbox, Grid).
* **Bootstrap 5:** Sistema de rejilla y componentes base.
* **JavaScript (Vanilla):** Lógica de manipulación del DOM y efectos de la tarjeta.
* **Bootstrap Icons:** Librería de iconos vectoriales para una interfaz limpia.
* **Google Fonts:** Tipografía *Plus Jakarta Sans* para un acabado premium.

## 🛠️ Instalación y Uso

1.  Clona este repositorio o descarga los archivos:
    ```bash
    git clone [https://github.com/tu-usuario/securepay-checkout.git](https://github.com/tu-usuario/securepay-checkout.git)
    ```
2.  Asegúrate de mantener la siguiente estructura de carpetas:
    ```text
    /
    ├── index.html
    ├── assets/
    │   ├── css/
    │   │   └── styles.css
    │   ├── js/
    │   │   └── script.js
    │   └── img/
    │       └── fondo.jpg
    ```
3.  Abre el archivo `index.html` en tu navegador favorito.
